CHEMLAB — Chemistry Learning Website

เปิดใช้งาน:
1. แตก ZIP ไฟล์นี้
2. เปิด index.html ใน Chrome/Edge หรือเปิดโฟลเดอร์ด้วย VS Code
3. ใช้งานได้แบบ static website ไม่ต้องติดตั้ง backend

หน้าเว็บแยกกัน:
- index.html: หน้าหลัก
- practice.html: ฝึกดุลสมการ
- naming.html: ฝึกสุ่มอ่านชื่อสารและคำนำหน้า 1–10
- periodic.html: ตารางธาตุแบบกดดูข้อมูล 118 ธาตุ
- lessons.html: บทเรียน
- style.css: ธีมและ responsive design
- practice.js: คลังโจทย์และระบบตรวจคำตอบ

ข้อควรทราบ:
- เว็บไซต์นี้เป็น static site สามารถอัปโหลดทั้งโฟลเดอร์ไปยัง Netlify Drop ได้
- จำนวนโจทย์ฝึกแสดงจากสมการที่ไม่ซ้ำหลังกรองสมการซ้ำ ไม่ใช้การสุ่มซ้ำมาทำให้ยอดสูงเกินจริง
- ตัวแก้สมการใช้การค้นหาสัมประสิทธิ์ในช่วงจำกัดและอาจไม่รองรับสมการซับซ้อนทุกประเภท
- ข้อมูลชื่อธาตุภาษาไทยและประเภทเป็นข้อมูลเพื่อการเรียนรู้ ควรตรวจสอบกับหนังสือเรียนหากนำไปทำงานส่ง


ปรับปรุงเพิ่มเติม: กฎ mono- สำหรับสารโคเวเลนต์, ไอออนหลายอะตอม, ปฏิกิริยากรด–เบสและรีดอกซ์, คำอธิบายแทนที่เดี่ยว, หมายเหตุไฮโดรเจน/แลนทาไนด์/แอกทิไนด์ และการเทียบเลขหมู่ IUPAC กับระบบเก่า IA–VIIIA
